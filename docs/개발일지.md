# 개발일지 — 구매 분석 대시보드 (hd-project01)

- 프로젝트: 빅데이터 기반 장비 모델별 구매 품목 및 협력업체 분석 대시보드
- 기획: 정하진 (생성형 AI 업무자동화 전문가과정 1차수)
- 개발 기간: 2026-08-21
- 저장소: https://github.com/aebonlee/hd-project01

---

## 1. 요구사항 분석

Padlet 프로젝트 기획서를 작업 지시서(`CLAUDE.md`)로 정리하여 개발 기준으로 삼았다. 핵심 요구는 네 가지였다.

1. 구매 데이터(품번·업체·물량·금액)와 장비 모델 데이터(품번·모델·톤급 코드)를 **품번 기준으로 조인**
2. 톤급 코드 변환 규칙: `2X→2톤급 … 8X→8톤급`, 세 자리 수는 ÷10 (`100→10톤급 … 180→18톤급`), **숫자 순 정렬**
3. **톤급 → 장비 모델 → 품번 → 협력업체** 계층 드릴다운과 각 레벨의 업체 비중(%) 시각화
4. 업체 집중도(1위 업체 비중 N% 이상) 하이라이트 + 보고서(PDF)·엑셀 산출물

실제 사내 데이터는 제공되지 않으므로, 기획서 스키마대로 샘플 엑셀을 생성해 전체 파이프라인을 검증하고 실데이터를 올리면 그대로 동작하도록 컬럼 자동 매핑을 넣기로 했다.

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| 단일 HTML + 순수 JS (빌드 없음) | 수강생 개인 노트북에서 설치 없이 실행, GitHub Pages 배포 가능 (기획서 옵션 A) |
| 분석 로직을 `js/analysis.js`로 UI와 분리 | Node에서 단위 테스트 가능, 추후 Streamlit 등 다른 UI로 이식 용이 |
| SheetJS + Chart.js **로컬 번들**(`lib/`) | CDN 불가 환경(오프라인·사내망)에서도 동작 |
| KPI는 구매 원본 기준, 트리는 모델 연계 기준 이원화 | 1:N 품번(여러 모델 적용)을 모든 모델에 연계하라는 기획 요구를 지키면서 전체 합계의 중복 집계를 방지 |
| 컬럼명 자동 매핑(`COLUMN_ALIASES`) + 부분 일치 fallback | 실제 엑셀의 컬럼명이 다를 가능성에 대비 |

## 3. 구현 내역

1. **샘플 데이터 생성기** (`make_samples.py`): 품번 320개, 업체 9개사, 톤급 2X~180, 1:N 품번 25%, 복수 업체 공급 35% 포함. `data/*.xlsx` 2종과 임베디드 데모(`js/sample-data.js`)를 동일 데이터로 생성.
2. **분석 로직** (`js/analysis.js`): 톤급 코드 파서, 컬럼 자동 매핑, 조인(1:N·모델 미매칭 처리), 계층 트리 집계, 업체 비중, 집중도 하이라이트, KPI.
3. **대시보드 UI** (`index.html`, `js/app.js`): KPI 5종, 톤급별 구매 규모 막대 차트(클릭 시 필터), 업체 비중 도넛(상위 8개사+기타), 드릴다운 아코디언(레벨별 업체 점유 막대), 필터(톤급/모델/업체/집계 기준/경고 기준), 집중도 상위 표.
4. **산출물 기능**: 요약 보고서 인쇄(브라우저 PDF 저장 — 전체 현황/톤급별/모델별 업체 비중/집중도), 분석 결과 엑셀 내보내기(3개 시트).

## 4. 테스트 및 검증

- `node test/analysis.test.js` — 톤급 변환(2X/8x/100/180/145/오류값), 숫자 파싱(콤마·원), 컬럼 매핑, 1:N 조인, 트리 정렬, 업체 비중, 집중도, KPI, 필터 **전체 통과**
- headless Chromium 렌더링 검증: 샘플 로드 후 KPI 5개, 드릴다운 545 노드 생성, **콘솔 에러 0건**

## 5. 트러블슈팅

| 이슈 | 해결 |
|---|---|
| 개발 환경에서 CDN(jsdelivr) 차단으로 라이브러리 로드 실패 | npm 레지스트리에서 패키지를 받아 `lib/`에 로컬 번들 → 오프라인 실행 가능해지는 부수 효과 |
| 1:N 품번의 물량·금액이 KPI에 중복 집계됨 | KPI·업체 도넛은 품번×업체 유일 기준으로 별도 계산, 드릴다운 트리에만 모델 연계 중복 허용(기획 요구) 후 화면에 주석 표기 |
